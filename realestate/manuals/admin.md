# Admin

- **Setup → Settings**: company, default project and every rule; the **Land** tab for area units, the approval limit, province and land accounts.
- **Users & Roles**: one profile per person — Admin, Accounts, Land Manager, Sales Manager, Sales Agent, Recovery Officer, Society Manager, Projects, Maintenance, Customer.
- **Acceptance checks**: run after setup and after changes; every check shows its evidence.
- Only you can override due diligence (with a reason) and **Merge into boundary** (makes the acquired khasras the project map — it confirms first).
- Demo commands (`re-reset-demo`, `re-daily-data`) act only in mock mode on the demo project.
